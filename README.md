# Metzler LED Wandleuchte Up-Down — Staffelpreise (Concept)

An independent UX/UI redesign concept of a product detail page with a tiered-pricing
(**Staffelpreise**) buy box, shared as a portfolio work sample.

This is **not** an official Metzler GmbH product page or online store. Product names,
imagery and brand references remain the property of their respective owners. Content
shown is for design demonstration only.

Static **HTML/CSS/JS** — no build step, no dependencies, no backend. The pages carry
`noindex, nofollow`.

## Run

Any static server from this folder, e.g.:

```bash
python -m http.server 8000
```

Then open `metzler-led-wandleuchte.html` (the root `index.html` redirects there).
